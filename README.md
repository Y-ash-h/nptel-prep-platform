# NPTEL Exam PrepMaster 🎓

An interactive exam and practice preparation platform for:
1. **Scalable Data Science** (120 Questions across 8 Assignments)
2. **Machine Learning for Earth System Sciences** (80 Questions across 8 Assignments)

Total: **200 authentic questions** extracted verbatim from course assignments with verified answer keys, detailed mathematical solutions, and diagrams.

---

## 🎯 Test Modes
- **50 Random Questions**: Comprehensive exam simulation sampled across all 8 assignments.
- **20 Random Questions**: Fast practice sprint for rapid revision.
- **Full Course Marathon**: All questions in the course jumbled together.
- **Per-Assignment Tests**: Topic-wise practice for Assignments 1 through 8 individually.
- **Dynamic Option Jumbling**: Randomizes choice positions ($A, B, C, D$) to prevent answer position memorization.
- **Exam Simulation vs. Practice Mode**: Switch between timed test conditions or instant feedback with step-by-step solutions.

---

## 📊 Scoring & Analytics
The application computes:
- **Raw Marks**: `User Marks / Total Questions`
- **Accuracy**: `(User Marks / Total Questions) × 100%`
- **NPTEL Scaled Score**:
  $$\text{Percentage} = \left(\frac{\text{User Marks}}{\text{Total Marks of Assignment}}\right) \times \frac{3}{4} \times 100$$
- Detailed question-by-question review with filters for mistakes, skipped, and flagged items.
